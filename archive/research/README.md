# 研究档案

这里保留已关闭研究和不在当前运行依赖链中的历史实现。归档保留源码，避免以后换名重做。

| 内容 | 位置 | 使用方法 |
| --- | --- | --- |
| 已关闭 A2 研究 | [closed/a2](closed/a2/) | 先核对原结论、身份和重新开启条件 |
| V18 / V20 历史源码 | [legacy/scripts](legacy/scripts/) | 用旧文件名检索，manifest 记录原路径 |
| 本次路径映射 | [legacy/manifest.json](legacy/manifest.json) | 原路径、新路径、原字节 SHA-256 |
| 当前研究复用表 | [研究索引](../../docs/research/README.md) | 检查已有身份、别名、旧结论与状态冲突 |

归档源码按原字节保存，部分脚本依赖原来的相对路径，不能直接在归档目录运行。
需要复用时，先通过现有注册表查询和提案检查，再在隔离目录恢复 manifest 记录的
原路径及必要依赖。优先提取或扩展已有实现，不建立平行版本。

仍被当前脚本调用的旧模块及其依赖留在 `scripts/v16`、`scripts/v18`、`scripts/v20`。
根目录带冻结路径或 SHA 约束的模块也保留原位。归档不改变研究状态，也不删除原始结果。
