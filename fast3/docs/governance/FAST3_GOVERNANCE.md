# FAST3 governance

FAST3 is research-only. Canonical data at `D:\us-tech-quant-data\fast3` is
read-only; formal results are at `D:\us-tech-quant-results\fast3`. No broker,
paper-broker, live, order-generation, or official-adoption action is permitted.

Each stage freezes its scope/configuration before model results. Confirmation is
unread until a separately frozen eligible champion exists. The machine-readable
state and registries are authoritative; Markdown files are validated human views.
