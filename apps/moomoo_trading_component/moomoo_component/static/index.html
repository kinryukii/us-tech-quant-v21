接口约定

所有策略共享同一份执行与风控规则。

v1
strategy_id / revision
策略唯一标识与版本号，用于切换和追踪。
asof / expires_at
带时区的信号生成时间与失效时间。
provenance
demo（离线演示）、live（实时信号）或 historical（历史记录）。live 指信号来源，交易仍仅为模拟。
targets
以 US.AAPL 形式指定标的，target_qty 为非负整数目标数量。
source
可选的来源说明，便于识别上游系统。
